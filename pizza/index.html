Pizza TTS

Pizza TTS is an open text to speech model. It's 32mb, runs efficiently on a phone, and sounds good.

Pizza is pretty fast and sounds pretty good. My main competition is Paradee, which is faster and also sounds great. But I wanted support for more languages than are supported by Paradee, so I had to make my own. Here’s a comparison between Pizza and some other models:

Download the model on Hugging Face (link coming soon), read the code, or use it today:

import {loadVoice} from './lexide-speech/index.js'
import {loadEspeak} from './espeak-ng/index.mjs'

const espeak = await loadEspeak('en-us')
const voice = await loadVoice('eng', espeak)
const {samples, sampleRate} = await voice.speak('Hello!')
voice.release()
